# Stellar Burgers — юнит-тесты

Юнит-тесты бизнес-логики приложения Stellar Burgers: булки, ингредиенты, сборка бургера и расчёт цены.

**Стек:** Python · pytest · unittest.mock · pytest-cov · Allure

## Что проверяется

16 тестов, покрытие классов `Bun`, `Burger`, `Ingredient` и `Database` — 100%.

| Класс | Тестов | Что проверяется |
|---|---|---|
| `Burger` | 6 | добавление булки, добавление, удаление и перемещение ингредиентов, итоговая цена, чек |
| `Ingredient` | 6 | название, цена и тип для соуса и начинки |
| `Bun` | 2 | название и цена |
| `Database` | 2 | списки доступных булок и ингредиентов |

## Как устроен проект

- Зависимости `Burger` подменены моками (`unittest.mock.Mock`), поэтому тесты бургера проверяют только его собственную логику.
- Тестовые данные вынесены в `data.py`, моки и база — в фикстуры `conftest.py`.

```
praktikum/      исходный код приложения
tests/          тесты, по файлу на класс
conftest.py     фикстуры с моками
data.py         тестовые данные
```

## Запуск

```bash
pip install -r requirements.txt
pytest --cov=praktikum --cov-report=html --alluredir=allure_results
allure serve allure_results
```

Отчёт о покрытии появится в `htmlcov/index.html`.
